## C001: 기존 검수 수행 보고 있음 / 원본 검수표 확인 대기
이전 인계 문서 snippet.txt 3쪽에서 사용자가 C001 PDF를 직접 보며 검수표를 확인·수정했다고 보고한 기록을 확인했다. T117 시각 오타와 REVIEWD 철자 수정 보고도 있다. 이미 수행한 사람 검수를 이유 없이 처음부터 다시 요구하지 말라는 지시가 있다.

따라서 앞선 '사람 검수 0/7', 'C001 미검수' 표시는 철회한다. 정확한 상태는 '기존 사람 검수 수행 보고 확인 / 실제 XLSX 셀별 범위·승인 확인 대기'다. 과거 보고만으로 모든 행을 승인하거나 TEAM_APPROVED로 승격하지 않는다.

## 원본 위치와 접근 한계
과거 업로드 목록에서 PDF_EVIDENCE_MATRIX.xlsx (file_L3ejxzNpM3c3bHUWVcmcHf, 목록 날짜 2026-11-02)를 발견했다. 이 ID는 기존 문서 목록의 식별자이며 현재 대화의 실제 셀 읽기 권한은 없다. 읽기 도구는 'Spreadsheet ID is not an attachment in this operation'을 반환했고, 현재 허용 첨부 목록에도 XLSX가 없다. 삭제·부재·내용 오류라고 단정하지 않는다. 이 파일이 최신 수정본인지도 아직 검증하지 않았다.

## 재개 방식
1. 기존 최신 XLSX 원본의 읽기 접근을 회복한다. PDF 전체 재검수부터 요청하지 않는다.
2. 원본을 변경하지 않고 시트·좌표·자료형·원문·decision·실제 reviewer/time·승인 범위를 확인한다. 문서 검색/OCR로 셀을 복원하지 않는다.
3. 기존 PDF 버전·해시와 검수 범위를 대조한다. 이미 확인된 동일 항목은 재사용한다.
4. 파일 버전 변경·값 충돌·근거 누락이 있는 항목만 좁혀 추가 확인한다.
5. REVIEWED_BY_MEMBER3와 TEAM_APPROVED를 구분하며 실제 승인 없이 Gold를 동결하지 않는다.
