# 화면 확보 목록

아래는 촬영 계획이다. 실제 캡처 파일은 이번 작업에서 확보하지 않았다. 개인정보와 자격증명은 제외한다.

| 순서 | 필요한 장면 | 함께 확인할 증거 | 상태 |
|---|---|---|---|
| 1 | C001 세 문서 입력 | 파일명·File ID·PDF SHA·동일 사례 | NOT_VERIFIED |
| 2 | 저장 설정 및 운영 실행 | AI 워크플로우 ID·Config 버전·단일 운영 Job | NOT_VERIFIED |
| 3 | Normalize 출력 | Step ID·Native 원본 SHA·문서 귀속 | NOT_VERIFIED |
| 4 | Python 계산 | 입력/출력 SHA·코드 HEAD·실행 종류 | NOT_VERIFIED |
| 5 | 독립 QA | QA Job·입력 SHA와 Normalize 연결 | NOT_VERIFIED |
| 6 | C013 차단 | 동일 Case의 충돌 원문·차단 결과 | NOT_VERIFIED |
| 7 | 평가 제한 | 승인 Gold 여부·측정 분모·미측정 표시 | NOT_VERIFIED |

구도훈에게 기존 화면과 Native 기록을 요청하고 윤현준/최유석 결과와 연결한다. 새 실행을 임의로 시작하지 않는다.
