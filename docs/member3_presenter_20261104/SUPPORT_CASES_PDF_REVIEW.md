# C008·C013·C017 PDF 본문 AI 대조 결과

사용자가 이 대화에 첨부한 PDF 9개의 읽힌 1쪽 본문을 확인했다. 이는 사람 검수·Gold 승인·코드 실행·원본 SHA-256 검증이 아니다. 원본 PDF와 기존 Gold DRAFT는 수정하지 않았다. 기존 비교 후보는 bcbf16052421add97accaa796dc519e0a16f25cc의 각 extraction_gold.DRAFT.json이다. 후보를 먼저 읽었으므로 맹검 독립 검수라고 부르지 않는다.

## C008 — 부분 입고
- SYN-C008_purchase_order.pdf 1쪽 기본정보: C008-PO / PO1 / Original delivery 2026-11-03. 품목 표는 A/R1/40 EA, A/R2/60 EA 두 행.
- SYN-C008_delivery_notice.pdf 1쪽: C008-NOTICE / PO1 / 2026-11-03→2026-11-08. 품목 표는 A/R2/60 EA만 기재. 표 아래 문구는 열거된 입고만 변경되고 다른 입고는 기존 날짜 유지라고 명시.
- SYN-C008_quotation.pdf 1쪽: C008-QUOTE / PO1 / Q008 / S1 / Arrival date 2026-11-04 / 1000.00 KRW/EA / 운송비 500 KRW 견적당 1회 / A 공급 가능량 60 EA. 구매는 실행되지 않은 견적임.
- 비교: 기존 초안의 핵심 식별자·입고 두 행·변경 대상 R2·날짜·견적 조건과 일치한다. R1까지 변경하거나 R1/R2를 한 행으로 대체하면 원문 역할을 잃는다. 중복 배분 방지·부족량·비용의 실제 엔진 동작은 아직 검증하지 않았다.

## C013 — PO 충돌
- SYN-C013_purchase_order.pdf 1쪽: C013-PO / PO1 / 2026-11-03 / A R1 100 EA.
- SYN-C013_delivery_notice.pdf 1쪽: C013-NOTICE / PO999 / 2026-11-03→2026-11-08 / A R1 100 EA.
- SYN-C013_quotation.pdf 1쪽: C013-QUOTE / Related PO PO1 / Q013 / S1 / 2026-11-04 / 1000.00 KRW/EA / 운송비 500 KRW 견적당 1회 / A 가능량 60 EA. 발주 완료가 아님.
- 비교: 기존 초안과 핵심 내용 일치. 실제 문자는 알파벳 O가 들어간 PO1/PO999이며 P01/P0999로 바꾸지 않는다. PO999 추출 자체는 원문에 맞는 값이다. 이를 PO1에 자동 연결하는지 여부는 별도 안전 동작 시험 대상이다. 이번에 차단 성공을 실행 검증하지 않았다.

## 공통 제한
9개 문서 모두 합성 시험 자료/DRAFT 표시가 있고 Human label review pending 문구가 있다. 이 문구는 파일 작성 당시 선언이지 사용자 현재 검수 부재를 확정하는 기록은 아니다. 재고와 고객 주문은 별도 trusted JSON 입력이며 PDF만으로 부족량·구매비용·엔진 결과를 확정하지 않는다.
